## Workflows

- **GitHub Workflow Activities** updates `index.html` and this README, then commits the changes. It runs on pushes to `main` or manually, only for `Sakura-zz26`.
- **Publish GitHub Pages** publishes the four HTML files only when manually started. First enable **Settings → Pages → Source → GitHub Actions**, then select **Actions → Publish GitHub Pages → Run workflow → main**. No repository variable is needed. Private repositories require a plan that supports Pages.

## Lecture 1 evidence

```bash
python3 scripts/run_git_practicals.py --remote /tmp/git-practical-remote.git --run-id local-demo --output /tmp/git-practical-evidence
```
